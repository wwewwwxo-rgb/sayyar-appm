# سيّار SAYYAR — مشروع أندرويد

هذا المصدر يحتوي على **5 ملفات فقط**. ارفع محتويات المجلد إلى مستودع GitHub، وسيبني GitHub Actions ملف APK تلقائياً.

## طريقة الرفع من Termux

1. فك ضغط `SAYYAR_PREMIUM_5_FILES.zip`.
2. افتح المجلد الناتج وتأكد أن الملفات الخمسة موجودة، ومنها `.github/workflows/build-apk.yml`.
3. ارفع الملفات إلى جذر مستودع GitHub `sayyar`، وليس مجلداً متداخلاً داخل المستودع.
4. افتح تبويب **Actions** وانتظر انتهاء `Build SAYYAR APK`.
5. افتح تشغيل البناء الناجح، ثم من **Artifacts** نزّل `SAYYAR-APK` وفك ضغطه لتحصل على ملف APK.

### أوامر Termux (إذا كان الملف في Downloads)

```bash
termux-setup-storage
cd ~/storage/downloads
unzip -o SAYYAR_PREMIUM_5_FILES.zip -d SAYYAR_PREMIUM
cd SAYYAR_PREMIUM
find . -maxdepth 4 -type f
```

بعدها ارفع الملفات إلى GitHub من المتصفح أو باستخدام Git. لا ترفع مجلد `SAYYAR_PREMIUM` كطبقة إضافية؛ يجب أن يكون `pubspec.yaml` و`lib/` و`.github/` في جذر المستودع.

## المزايا الحالية

- واجهة عربية داكنة بلون أخضر زمردي، وهوية SAYYAR.
- خريطة OpenStreetMap تفاعلية قابلة للتحريك والتكبير.
- طلب إذن الموقع وتحديد موقع الهاتف عند توفر خدمة الموقع.
- بحث عن وجهة عبر Nominatim، ثم عرض نتيجة على الخريطة.
- خيارات مسار توضيحية، شاشة بلاغات، أماكن محفوظة، إعدادات وحساب.
- تعليمات صوتية أساسية عبر تحويل النص إلى كلام.

## ملاحظات مهمة

- هذه نسخة أولية قابلة للبناء وليست بديلاً مكتملاً عن Waze: بيانات الازدحام المباشر، الإبلاغ الجماعي، وحساب المسارات المرورية الفعلية تحتاج خدمات خلفية وواجهات API موثوقة.
- الخرائط تحتاج اتصال إنترنت. خريطة OpenStreetMap هنا خريطة شوارع وليست صور أقمار صناعية ثلاثية الأبعاد.
- لا تضع مفاتيح API سرية داخل المستودع.
